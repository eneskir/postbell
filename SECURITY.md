# Security

Postbell is a Windows desktop app. It reads content packages from folders you choose and keeps its data on your computer. If you find a security problem, please report it privately: open the Security tab of this repository and choose "Report a vulnerability". Please don't open a public issue for it.

Examples of what to report:

- a content package that makes Postbell read or show a file outside the folders you added
- a link in a package that opens something other than the platform's share page
- a way for another program or user to change Postbell's data or its installed files

Only the latest version on the `main` branch is supported.
