# Contributing

Postbell is a small project with a clear direction: a desktop app that gets content ready to share on several accounts, while you post it yourself. Product and design decisions are made by its maintainer.

## Issues

Use one of the issue forms:

- **Bug report:** what you did, what you expected and what happened, with your Windows version and the Postbell version. Leave out account names and files you don't want to share.
- **Idea:** something you would like Postbell to do. Every idea is read, but not every idea will be built.

If you use an AI tool to write an issue, read it before posting. You are responsible for what you post.

## Pull requests

Pull requests are open to maintainers only for now. If you have a fix in mind, describe it in an issue.

Contributions are accepted under the MIT License, the same license as the rest of the code.

## Behavior

Be kind and stay on topic. Spam, repeated pings and abuse lead to a ban.
