# Image sources

The SVGs in this folder are taken from the "90 Kütüphane" page of the Figma file "Postbell" with `tools/figma/export.js` and written by `npm run figma-import`; they are not edited by hand. The "Notice" section of this file goes into `THIRD_PARTY_NOTICES.md`.
